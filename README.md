### 👋 About Me

I am a **Database Administrator (DBA)** based in Nagpur, India. By day, I specialize in enterprise **MS SQL Server** database architectures, high availability, disaster recovery, and query performance optimization.

In my free time, I treat modern AI as my creative companion—building interactive 3D WebGL worlds, autonomous AI agents, and experimental full-stack tools just for the love of engineering and innovation!

- 🛡️ **Primary Domain**: MS SQL Server (2016–2022), AlwaysOn Availability Groups, Windows Failover Clustering, Database Mirroring, Index & Performance Tuning, Backup Automation.
- 🚀 **Creative Side (For Fun with AI)**: Interactive 3D WebGL / Three.js simulations, full-stack reactive apps (React, Next.js 15, Vite), and autonomous multi-agent pipelines (Python, FastAPI).
- 💡 **Philosophy**: Industrial database reliability meets playful, rapid prototyping powered by modern AI agents.

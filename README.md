## 👋 About Me

I am a **Database Administrator specializing in Microsoft SQL Server**.

My professional work focuses on database administration, backup and recovery, monitoring, troubleshooting, and automation.

Outside work, I enjoy building websites, interactive experiences, and AI-related personal projects **for fun, with help from AI tools**. These projects are a way to explore ideas, learn new technologies, and turn concepts into working applications.

**Database administration is my profession. AI-assisted development is my creative hobby.**

- 🛡️ **Professional focus:** SQL Server administration, backup and recovery, performance troubleshooting, and database monitoring.
- 🎨 **Personal interests:** Web development, interactive 3D experiences, dashboards, and AI assistants.
- 🤖 **How I build:** Using AI tools to help write, understand, debug, and improve code while learning along the way.
- 🔍 **Approach:** Practical solutions, continuous learning, and checking that things work as intended.
